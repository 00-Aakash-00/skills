# skills

Agent Skills by [@00-Aakash-00](https://github.com/00-Aakash-00).

Works with Claude Code, Codex, Cursor, and any agent the [`skills`](https://github.com/vercel-labs/skills) CLI supports.

## Install

```bash
# everything
npx skills add 00-Aakash-00/skills

# one skill
npx skills add 00-Aakash-00/skills --skill ux-guidelines
```

## Skills

| Skill | Description |
| --- | --- |
| [`ux-guidelines`](skills/ux-guidelines/SKILL.md) | Behavioral UX guidelines — the four screen states (loading, error, empty, success), graceful degradation, action feedback, and forgiving forms. |
